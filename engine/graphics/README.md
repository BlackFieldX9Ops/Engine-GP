# Graphics Engine

Renderização via WebGL 2.0.

## Organização

- `common/` — Componentes compartilhados (texturas, materiais, shaders base).
- `2d/` — Renderer 2D, sprites, tilemaps, batching, câmeras.
- `3d/` — Placeholder para futura expansão (não implementado).

## Status

Estrutura criada. Implementação do renderer 2D é prioridade da Fase 1.
