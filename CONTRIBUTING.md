# Contribuindo para o ENGINE-GP

## Diretrizes

1. Siga a arquitetura modular documentada.
2. Não misture Editor e Runtime.
3. Mantenha separação clara entre sistemas.
4. Documente mudanças significativas.
5. Prefira commits descritivos.
6. Não introduza dependências pesadas sem justificativa.

## Processo

- Crie branches a partir de `main`.
- Abra Pull Requests com descrição clara.
- Garanta que a documentação seja atualizada quando a estrutura ou APIs mudarem.
