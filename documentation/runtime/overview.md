# Game Runtime

Responsável por executar jogos independentemente do Editor.

## Responsabilidades

- Inicialização do runtime.
- Carregamento de projetos e cenas.
- Execução do Game Loop.
- Coordenação de renderização, física, áudio e entrada.
- Gerenciamento de recursos durante a execução.

## Separação

O Runtime não depende do Editor. Pode ser empacotado separadamente para builds finais.

## Status

Estrutura planejada. Implementação futura.
