# Padrões de Desenvolvimento — ENGINE-GP

## Nomenclatura

- Classes: PascalCase
- Funções e variáveis: camelCase
- Constantes: UPPER_SNAKE_CASE
- Arquivos: PascalCase.js para classes principais

## Organização

- Módulos com responsabilidade única.
- Comunicação via APIs públicas e eventos.
- Sem dependências circulares.
- Editor não acessa detalhes privados do motor.

## Qualidade

- Comentários claros de responsabilidade nos skeletons.
- Documentação alinhada à estrutura real.
- Diferenciar claramente o que está planejado do que está implementado.

## Tecnologias

Usar exclusivamente a stack oficial. Não introduzir frameworks pesados sem justificativa.
