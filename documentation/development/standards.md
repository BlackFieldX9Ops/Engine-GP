# Padrões de Desenvolvimento

## Convenções

- JavaScript ES2025+ consistente.
- Nomenclatura clara e descritiva (PascalCase para classes, camelCase para funções/variáveis).
- Separação entre lógica, apresentação e infraestrutura.
- Imports/exports organizados.

## Tratamento de Erros e Logs

- Sistema padronizado de erros.
- Logs centralizados via Logger do core.

## Testes

- Testes unitários e de integração planejados em `tests/`.
- Não declarar testes aprovados se não executados.

## Versionamento

- Commits descritivos.
- Branch main protegida por padrão.

## Dependências

- Preferir dependências pequenas e justificadas.
- Não introduzir frameworks pesados sem necessidade.

## Documentação

- Cada módulo importante possui documentação correspondente.
- Diferenciar claramente o que está planejado do que está implementado.
