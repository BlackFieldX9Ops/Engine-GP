# Editor GP — Visão Geral

Editor visual integrado ao motor, separado do runtime.

## Módulos Planejados

- Application / Interface principal.
- Panels e layout adaptativo.
- Viewport.
- Project Manager.
- Scene Editor.
- Hierarchy e Inspector.
- Asset Manager.
- Editors especializados (Sprite, Animation, Tilemap, Physics, Particle, Audio).
- Debugger, Profiler, Build Manager.

## Comunicação

O Editor acessa o motor exclusivamente via APIs públicas e sistema de eventos. Não acessa detalhes privados internos.

## Interface

- Layout adaptativo (desktop e mobile/touch).
- Painéis reorganizáveis.
- Suporte a mouse, teclado e touch.
- Tema visual profissional.

## Status

Arquitetura e estrutura de pastas em construção. Implementação de UI ainda não iniciada.
